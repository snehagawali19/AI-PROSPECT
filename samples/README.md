# samples/

Generated by `python -m scripts.run_test_queries` against a running instance with real keys:

- `q1.json` … `q6.json`: spec-shaped responses for the 5 mandatory test queries plus 1 unseen query
- `q*_evidence.json`: the same runs with `include_evidence=true` (sources, signals, merge reasons, platform_status, meta)
- `RESULTS.md`: summary table (prospects, links per platform, contacts, search calls, latency) to paste into the main README

This folder is intentionally empty in the handoff package: no results were generated without live API keys,
and none were invented. Before committing generated files to a public repository, remove contact details of
private individuals (business listings are fine).
